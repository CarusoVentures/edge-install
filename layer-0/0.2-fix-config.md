# Layer 0.2: Fix Known Broken Config

## What This Does

Fixes 5 known issues from the initial setup: placeholder gateway token, wrong timezone, broken cron jobs, memory file clutter, and missing SSH keys.

## Prerequisites

- Layer 0.1 Security Hardening (DEPLOYED)

```bash

# Expected: 2026.3.22 or newer
```

## Deployment Steps

### Step 1: Generate Real Gateway Token

```bash
# Back up current config
cp /Users/edge/.openclaw/openclaw.json /Users/edge/.openclaw/openclaw.json.bak.0.2

# Generate a cryptographically random token and update config
python3 << 'PYEOF'
import json, secrets

token = secrets.token_urlsafe(32)

with open('/Users/edge/.openclaw/openclaw.json', 'r') as f:
    config = json.load(f)

# Navigate to gateway.auth.token — create path if needed
if 'gateway' not in config:
    config['gateway'] = {}
if 'auth' not in config['gateway']:
    config['gateway']['auth'] = {}
config['gateway']['auth']['token'] = token

with open('/Users/edge/.openclaw/openclaw.json', 'w') as f:
    json.dump(config, f, indent=2)

print(f"Gateway token set to: {token}")
PYEOF
```

**Verify:**
```bash

openclaw doctor --fix
# Should not report config errors
```

### Step 4: Fix Broken Cron Jobs

The Morning Brief and EOD Summary cron jobs fail because they run inside OpenClaw sessions that accumulate context. We'll disable them now and replace them with standalone scripts in later phases.

```bash
# Check current cron jobs
cat /Users/edge/.openclaw/cron/jobs.json | python3 -m json.tool

# Disable the broken jobs (don't delete — we'll replace them)
python3 << 'PYEOF'
import json

with open('/Users/edge/.openclaw/cron/jobs.json', 'r') as f:
    jobs = json.load(f)

print(f"Current jobs: {len(jobs)}")
for job in jobs:
    print(f"  - {job.get('name', 'unnamed')}: {job.get('schedule', 'no schedule')}")
    job['enabled'] = False

with open('/Users/edge/.openclaw/cron/jobs.json', 'w') as f:
    json.dump(jobs, f, indent=2)

print("All jobs disabled. Will be replaced by standalone scripts in Phase 4.")
PYEOF
```

### Step 5: Generate SSH Keys

```bash
# Create .ssh directory
mkdir -p /Users/edge/.ssh
chmod 700 /Users/edge/.ssh

# Generate Ed25519 key (more secure than RSA, smaller)
ssh-keygen -t ed25519 -C "edge@crusoeventures.com" -f /Users/edge/.ssh/id_ed25519 -N ""

# Set permissions
chmod 600 /Users/edge/.ssh/id_ed25519
chmod 644 /Users/edge/.ssh/id_ed25519.pub

# Display public key (Ryan will add this to GitHub)
echo "=== PUBLIC KEY (add to GitHub) ==="
cat /Users/edge/.ssh/id_ed25519.pub
```
