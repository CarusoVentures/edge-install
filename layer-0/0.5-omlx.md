# Layer 0.5: oMLX (Local Inference)

## What This Does

Installs oMLX for local model inference on Apple Silicon. Pulls Qwen 3 8B (chat/heartbeats) and mxbai-embed-large (embeddings). This replaces Ollama — 2x faster generation, 50% less RAM.

## Prerequisites

- Layer 0.2 (config fixes done)
- Homebrew installed at `/opt/homebrew/bin/brew`

## Pre-Flight Checks

```bash
# Verify Homebrew works
brew --version

# Check available RAM (need enough for 8B model — ~5GB)
python3 -c "import subprocess; r=subprocess.run(['sysctl','-n','hw.memsize'],capture_output=True,text=True); print(f'{int(r.stdout.strip())/(1024**3):.0f} GB total RAM')"

# Check disk space (need ~10GB for models)
df -h /Users/edge | tail -1

# Check if Ollama is installed (should NOT be — we use oMLX instead)
which ollama 2>/dev/null && echo "WARNING: Ollama is installed" || echo "OK: no Ollama"

# Check if oMLX is already installed
which omlx 2>/dev/null && echo "oMLX already installed" || echo "oMLX not installed yet"
```

## Deployment Steps

### Step 1: Install oMLX

```bash
brew tap jundot/omlx
brew install omlx
```

**Verify:**
```bash
omlx --version
# Should print version number

# If Gatekeeper blocks it:
# xattr -dr com.apple.quarantine $(which omlx)
```

### Step 2: Start oMLX Server

```bash
# Start oMLX temporarily for model pulls and testing
# (will be replaced by LaunchAgent in Step 5)
omlx serve &
OMLX_PID=$!

# Wait for startup
sleep 3

# Verify it's running
curl -sS http://localhost:8000/v1/models | python3 -m json.tool
# Should return JSON (possibly empty model list)
```

### Step 3: Pull Qwen 3 8B (Chat Model)

```bash
# Pull the model (Q4 quantization — ~5GB download)
omlx pull qwen3-8b

# This may take several minutes depending on network speed
# Verify it's available
omlx list
# Should show qwen3-8b
```

**Test chat:**
```bash
curl -sS http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3-8b",
    "messages": [{"role": "user", "content": "Say hello in one sentence."}],
    "max_tokens": 50
  }' | python3 -m json.tool
```

### Step 4: Pull mxbai-embed-large (Embedding Model)

```bash
# Pull embedding model
omlx pull mxbai-embed-large

# Verify
omlx list
# Should show both qwen3-8b and mxbai-embed-large
```

**Test embeddings:**
```bash
curl -sS http://localhost:8000/v1/embeddings \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mxbai-embed-large",
    "input": "Dan Caruso is the Managing Director of Crusoe Ventures"
  }' | python3 -c "import sys,json; r=json.load(sys.stdin); print(f'Embedding dim: {len(r[\"data\"][0][\"embedding\"])}')"
# Expected: Embedding dim: 1024
```

### Step 5: Create LaunchAgent for oMLX

oMLX needs to run as a persistent service so it's always available for heartbeats and embeddings.

```bash
# Kill the temporary oMLX process from Step 2 before starting the LaunchAgent
kill $OMLX_PID 2>/dev/null
sleep 2

cat > /Users/edge/Library/LaunchAgents/com.edge.omlx.plist << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.edge.omlx</string>
    <key>ProgramArguments</key>
    <array>
        <string>/opt/homebrew/bin/omlx</string>
        <string>serve</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
    <key>StandardOutPath</key>
    <string>/Users/edge/.openclaw/workspace/logs/omlx.stdout.log</string>
    <key>StandardErrorPath</key>
    <string>/Users/edge/.openclaw/workspace/logs/omlx.stderr.log</string>
    <key>EnvironmentVariables</key>
    <dict>
        <key>HOME</key>
        <string>/Users/edge</string>
    </dict>
</dict>
</plist>
EOF

# Create logs directory
mkdir -p /Users/edge/.openclaw/workspace/logs

# Validate plist
plutil -lint /Users/edge/Library/LaunchAgents/com.edge.omlx.plist

# Load the service (modern macOS syntax)
launchctl bootstrap gui/$(id -u) /Users/edge/Library/LaunchAgents/com.edge.omlx.plist

# Verify it's running
sleep 3
launchctl list | grep com.edge.omlx
curl -sS http://localhost:8000/v1/models | python3 -m json.tool
```

### Step 6: Configure OpenClaw Heartbeat to Use oMLX

```bash
python3 << 'PYEOF'
import json

with open('/Users/edge/.openclaw/openclaw.json', 'r') as f:
    config = json.load(f)

# Update heartbeat to use local oMLX model
agents = config.setdefault('agents', {})
defaults = agents.setdefault('defaults', {})
heartbeat = defaults.setdefault('heartbeat', {})
heartbeat['model'] = 'omlx/qwen3-8b'

with open('/Users/edge/.openclaw/openclaw.json', 'w') as f:
    json.dump(config, f, indent=2)

print("Heartbeat model set to omlx/qwen3-8b")
PYEOF

openclaw doctor --fix
```

## Verification

```bash
# 1. oMLX binary exists
which omlx && echo "OK" || echo "FAIL"

# 2. Both models pulled
omlx list
# Should show qwen3-8b and mxbai-embed-large

# 3. Server responding
curl -sS http://localhost:8000/v1/models > /dev/null && echo "OK: server up" || echo "FAIL: server down"

# 4. Chat works
curl -sS http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3-8b","messages":[{"role":"user","content":"Say OK"}],"max_tokens":10}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['choices'][0]['message']['content'])"

# 5. Embeddings work
curl -sS http://localhost:8000/v1/embeddings \
  -H "Content-Type: application/json" \
  -d '{"model":"mxbai-embed-large","input":"test"}' \
  | python3 -c "import sys,json; d=json.load(sys.stdin)['data'][0]['embedding']; print(f'OK: {len(d)} dims')"

# 6. LaunchAgent loaded
launchctl list | grep com.edge.omlx

# 7. OpenClaw config updated
python3 -c "import json; c=json.load(open('/Users/edge/.openclaw/openclaw.json')); print('Heartbeat model:', c.get('agents',{}).get('defaults',{}).get('heartbeat',{}).get('model','NOT SET'))"
```

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `omlx: command not found` | `brew link omlx` or add `/opt/homebrew/bin` to PATH |
| Gatekeeper blocks omlx | `xattr -dr com.apple.quarantine $(which omlx)` |
| Model pull hangs | Check network. Try `omlx pull --verbose qwen3-8b` |
| Server won't start (port in use) | `lsof -i :8000` — kill conflicting process |
| Out of memory during inference | Close other apps. 24GB should handle 8B model fine. |

## Rollback

```bash
launchctl bootout gui/$(id -u)/com.edge.omlx
rm /Users/edge/Library/LaunchAgents/com.edge.omlx.plist
brew uninstall omlx
brew untap jundot/omlx
```
