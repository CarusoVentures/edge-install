# Layer 0.6: Persistent Memory + Embeddings

## What This Does

Configures Edge's memory system with local embeddings via oMLX (mxbai-embed-large). Enables hybrid search (vector 0.7 + text 0.3). Structures memory into hot/warm/cold tiers.

## Prerequisites

- Layer 0.5 (oMLX installed with mxbai-embed-large)
- oMLX server running on localhost:8000

## Deployment Steps

### Step 1: Configure Embedding Provider

```bash
python3 << 'PYEOF'
import json

with open('/Users/edge/.openclaw/openclaw.json', 'r') as f:
    config = json.load(f)

# Configure embeddings to use local oMLX
# Per OpenClaw docs, embedding config goes under agents.defaults.memorySearch
agents = config.setdefault('agents', {})
defaults = agents.setdefault('defaults', {})
ms = defaults.setdefault('memorySearch', {})
ms['provider'] = 'ollama'
ms['model'] = 'mxbai-embed-large'
ms['enabled'] = True
ms['fallback'] = 'none'

# Enable hybrid search
ms['query'] = {
    'hybrid': {
        'enabled': True,
        'vectorWeight': 0.7,
        'textWeight': 0.3
    }
}

with open('/Users/edge/.openclaw/openclaw.json', 'w') as f:
    json.dump(config, f, indent=2)

print("Embedding config set: mxbai-embed-large via oMLX")
print("Hybrid search: vector 0.7 + text 0.3")
PYEOF

# Verify config is valid
openclaw doctor --fix
```

**Note:** The config keys above follow the official OpenClaw schema (`agents.defaults.memorySearch`). The `provider: "ollama"` works for any OpenAI-compatible embedding endpoint including oMLX. If `openclaw doctor` reports issues, read the error and adjust — the schema may evolve between versions.
