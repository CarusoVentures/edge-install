# Layer 0.6: Persistent Memory + Embeddings

## What This Does

Configures Edge's memory system with local embeddings via oMLX (mxbai-embed-large). Enables hybrid search (vector 0.7 + text 0.3). Structures memory into hot/warm/cold tiers.

## Prerequisites

- Layer 0.5 (oMLX installed with mxbai-embed-large)
- oMLX server running on localhost:8000

## KNOWN ISSUE: Embedding Provider Config (Resolved 2026-03-30)

**Problem:** The original deploy skill said `provider: "ollama"` works for any OpenAI-compatible endpoint including oMLX. This is WRONG. OpenClaw's "ollama" adapter only speaks the Ollama-native API format (`/api/embeddings`), not the OpenAI format (`/v1/embeddings`). oMLX only serves the OpenAI format. They are incompatible.

**What didn't work:**
- Setting `OPENAI_BASE_URL` env var — OpenClaw's embedding adapter ignores this env var entirely
- Using `provider: "ollama"` — it hits `/api/embeddings` which oMLX doesn't serve
- Adding `baseUrl` to the top-level memorySearch config — schema validation rejects unknown keys

**What works:** Use `provider: "openai"` with `remote.baseUrl` and `remote.apiKey` in the memorySearch config. The "openai" provider is just the API protocol name — it connects to localhost:8000 (oMLX), not to api.openai.com. The `remote.apiKey` can be any non-empty string because oMLX ignores it (set `skip_api_key_verification: true` in oMLX settings).

**Also:** mxbai-embed-large has a 512-token context window, but OpenClaw's default chunking is 400 tokens × 4 bytes = 1600 bytes, which exceeds it. You MUST set `chunking.tokens: 128` (128 × 4 = 512 bytes) to keep chunks within the model's limit.

## Deployment Steps

### Step 1: Configure Embedding Provider

```bash
python3 << 'PYEOF'
import json

with open('/Users/edge/.openclaw/openclaw.json', 'r') as f:
    config = json.load(f)

# Configure embeddings to use oMLX via the "openai" protocol adapter
# "openai" = the API format, NOT the company. Connects to localhost:8000 (oMLX).
agents = config.setdefault('agents', {})
defaults = agents.setdefault('defaults', {})
ms = defaults.setdefault('memorySearch', {})
ms['provider'] = 'openai'
ms['model'] = 'mxbai-embed-large'
ms['enabled'] = True
ms['fallback'] = 'none'

# Point at oMLX — this is the key config that makes it work
ms['remote'] = {
    'baseUrl': 'http://localhost:8000/v1',
    'apiKey': 'dummy'  # oMLX ignores this, but the adapter requires a non-empty value
}

# mxbai-embed-large has 512-token context — chunks MUST be smaller
ms['chunking'] = {
    'tokens': 128,   # 128 * 4 = 512 bytes per chunk
    'overlap': 24
}

# Enable hybrid search
ms['query'] = {
    'hybrid': {
        'enabled': True,
        'vectorWeight': 0.7,
        'textWeight': 0.3
    }
}

with open('/Users/edge/.openclaw/openclaw.json', 'w') as f:
    json.dump(config, f, indent=2)

print("Embedding config set: mxbai-embed-large via oMLX (openai adapter)")
print("Hybrid search: vector 0.7 + text 0.3")
print("Chunking: 128 tokens, 24 overlap")
PYEOF

# Verify config is valid
openclaw doctor --fix
```
