# Layer 0.4: Humanizer

## What This Does

Deploys a style filter that strips 24+ common AI writing patterns from Edge's output. Makes Edge sound like a human executive assistant, not a chatbot.

## Prerequisites

- Layer 0.3 (SOUL.md deployed — humanizer references it for tone)

## Pre-Flight Checks

```bash
# Verify SOUL.md exists and is updated
head -10 /Users/edge/.openclaw/workspace/SOUL.md

# Check if any humanizer config already exists
ls /Users/edge/.openclaw/workspace/config/humanizer* 2>/dev/null || echo "No humanizer config yet"

# Check exec-approvals to see if we need to allowlist any commands
cat /Users/edge/.openclaw/exec-approvals.json | python3 -m json.tool | head -20
```

## Deployment Steps

### Step 1: Create Humanizer Config

```bash
mkdir -p /Users/edge/.openclaw/workspace/config

cat > /Users/edge/.openclaw/workspace/config/humanizer.json << 'HUMANEOF'
{
  "enabled": true,
  "patterns": [
    {"match": "I'd be happy to", "replace": ""},
    {"match": "I'd be glad to", "replace": ""},
    {"match": "Certainly!", "replace": ""},
    {"match": "Of course!", "replace": ""},
    {"match": "Absolutely!", "replace": ""},
    {"match": "Great question!", "replace": ""},
    {"match": "That's a great question", "replace": ""},
    {"match": "I hope this helps", "replace": ""},
    {"match": "Hope that helps", "replace": ""},
    {"match": "Let me know if you", "replace": ""},
    {"match": "Feel free to", "replace": ""},
    {"match": "Don't hesitate to", "replace": ""},
    {"match": "I'm here to help", "replace": ""},
    {"match": "Happy to help", "replace": ""},
    {"match": "Is there anything else", "replace": ""},
    {"match": "I understand your", "replace": ""},
    {"match": "That being said", "replace": "That said"},
    {"match": "It's worth noting that", "replace": ""},
    {"match": "It's important to note", "replace": "Note:"},
    {"match": "In terms of", "replace": "For"},
    {"match": "At the end of the day", "replace": ""},
    {"match": "Moving forward", "replace": ""},
    {"match": "Going forward", "replace": ""},
    {"match": "leverage", "replace": "use"},
    {"match": "utilize", "replace": "use"},
    {"match": "facilitate", "replace": "help with"},
    {"match": "streamline", "replace": "simplify"},
    {"match": "robust", "replace": "solid"},
    {"match": "comprehensive", "replace": "full"},
    {"match": "delve into", "replace": "look at"},
    {"match": "deep dive", "replace": "close look"}
  ],
  "rules": [
    "Never start a message with 'I'",
    "Never use exclamation marks in professional context",
    "Never use more than one emoji per message",
    "Keep paragraphs to 2-3 sentences max",
    "Lead with the answer, not the reasoning",
    "Use contractions (it's, don't, we'll)",
    "Prefer active voice",
    "No hedging phrases (might, perhaps, it seems like)",
    "Reference SOUL.md for tone"
  ]
}
HUMANEOF
```

### Step 2: Add Humanizer Reference to SOUL.md

Add a line to SOUL.md that references the humanizer:

```bash
# Check if humanizer is already referenced
grep -i "humanizer" /Users/edge/.openclaw/workspace/SOUL.md || echo "Not referenced yet"

# If not referenced, append to SOUL.md
cat >> /Users/edge/.openclaw/workspace/SOUL.md << 'EOF'

## Writing Style

All outbound text passes through the humanizer filter (config/humanizer.json). This strips AI-isms and enforces natural writing. Read humanizer.json for the full pattern list and rules.
EOF
```

### Step 3: Add to AGENTS.md

```bash
# Check current AGENTS.md
cat /Users/edge/.openclaw/workspace/AGENTS.md

# Append humanizer instruction
cat >> /Users/edge/.openclaw/workspace/AGENTS.md << 'EOF'

## Humanizer

Before sending any message to Dan or Emily via Telegram, or drafting any email:
1. Read config/humanizer.json
2. Remove all matched patterns from your output
3. Follow all rules listed in the config
4. Keep it short. Dan wants need-to-know only.
EOF
```

## Verification

```bash
python3 -c "import json; json.load(open('/Users/edge/.openclaw/workspace/config/humanizer.json')); print('OK: valid JSON')"

# 2. Pattern count
python3 -c "import json; h=json.load(open('/Users/edge/.openclaw/workspace/config/humanizer.json')); print(f'{len(h[\"patterns\"])} patterns, {len(h[\"rules\"])} rules')"

# 3. SOUL.md references humanizer
grep -q "humanizer" /Users/edge/.openclaw/workspace/SOUL.md && echo "OK: SOUL.md references humanizer" || echo "FAIL"

# 4. AGENTS.md references humanizer
grep -q "humanizer" /Users/edge/.openclaw/workspace/AGENTS.md && echo "OK: AGENTS.md references humanizer" || echo "FAIL"
```
