# Layer 0.7: Lossless Claw (Context Management)

## What This Does

Installs the Lossless Claw plugin for zero-loss context management. When a conversation approaches the context limit, instead of lossy compaction, it uses intelligent summarization (via local oMLX model) to preserve all important information.

## Prerequisites

- Layer 0.5 (oMLX running for summary generation)

## Pre-Flight Checks

```bash
# Verify OpenClaw plugins directory
openclaw plugins list 2>/dev/null || echo "Checking plugins manually..."
ls /Users/edge/.openclaw/plugins/ 2>/dev/null || echo "No plugins directory yet"

# Verify oMLX is running (used for cheap summarization)
curl -sS http://localhost:8000/v1/models > /dev/null && echo "OK: oMLX running" || echo "FAIL: oMLX not running"

# Check current compaction setting
python3 -c "import json; c=json.load(open('/Users/edge/.openclaw/openclaw.json')); print('Compaction:', c.get('compaction', 'not set'))"
```

## Deployment Steps

### Step 1: Install Lossless Claw Plugin

```bash
openclaw plugins install @martian-engineering/lossless-claw
```

**If the command fails** (plugin command might not exist in this OpenClaw version):
```bash
# Check if plugins are npm-based
ls /Users/edge/.openclaw/plugins/ 2>/dev/null

# Manual install via npm
cd /Users/edge/.openclaw/
npm install @martian-engineering/lossless-claw 2>/dev/null || echo "Try alternate install method"

# Check OpenClaw docs for plugin install method
openclaw help plugins 2>/dev/null
```

### Step 2: Configure Lossless Claw

```bash
python3 << 'PYEOF'
import json

with open('/Users/edge/.openclaw/openclaw.json', 'r') as f:
    config = json.load(f)

# Back up
with open('/Users/edge/.openclaw/openclaw.json.bak.0.7', 'w') as f:
    json.dump(config, f, indent=2)

# Register lossless-claw as the context engine and configure it
# Per OpenClaw docs: plugins.slots.contextEngine + plugins.entries.<id>.config
plugins = config.setdefault('plugins', {})
slots = plugins.setdefault('slots', {})
slots['contextEngine'] = 'lossless-claw'

entries = plugins.setdefault('entries', {})
entries['lossless-claw'] = {
    'config': {
        'freshTailCount': 32,
        'contextThreshold': 0.75,
        'summaryModel': 'omlx/qwen3-8b'
    }
}

with open('/Users/edge/.openclaw/openclaw.json', 'w') as f:
    json.dump(config, f, indent=2)

print("Lossless Claw configured:")
print("  freshTailCount: 32 (keep last 32 messages verbatim)")
print("  contextThreshold: 0.75 (trigger at 75% context usage)")
print("  summaryModel: omlx/qwen3-8b (free local model)")
PYEOF

# Verify config is still valid
openclaw doctor --fix
```

**If `openclaw doctor` reports errors**, the config keys may be wrong. Read the error output carefully and adjust. The plugin may use different config keys than assumed.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `openclaw plugins` not recognized | Plugin system may not exist in 2026.3.22. Check `openclaw help` for available commands. May need to install as npm package directly. |
| Config keys cause doctor errors | Remove the invalid keys. Read doctor output for valid schema. |
| Context still overflows | Check that freshTailCount and contextThreshold are actually being used. May need to update OpenClaw. |

## Rollback

```bash
# Restore config
cp /Users/edge/.openclaw/openclaw.json.bak.0.7 /Users/edge/.openclaw/openclaw.json

# Remove plugin
openclaw plugins uninstall @martian-engineering/lossless-claw 2>/dev/null
# Or: rm -rf /Users/edge/.openclaw/node_modules/@martian-engineering/lossless-claw
```
