### Step 2: Configure HEARTBEAT.md

The heartbeat runs every 30 minutes and should auto-save durable facts to memory.

```bash
cp /Users/edge/.openclaw/workspace/HEARTBEAT.md /Users/edge/.openclaw/workspace/HEARTBEAT.md.bak

cat > /Users/edge/.openclaw/workspace/HEARTBEAT.md << 'EOF'
# Heartbeat Instructions

On each heartbeat:

1. Review the current conversation context for durable facts worth remembering
2. Extract: new contacts mentioned, decisions made, tasks assigned, preferences stated, deadlines set
3. Write extracted facts to the appropriate memory tier:
   - MEMORY.md for hot/active items (preferences, this week's priorities, active deals)
   - Topic files in memory/ for warm items (contact details, meeting outcomes)
4. Keep MEMORY.md under 200 lines — move older items to topic files
5. Do not duplicate facts already in memory
6. Use the local model (oMLX) — this costs nothing
EOF
```
